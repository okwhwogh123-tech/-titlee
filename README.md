# 2023 산업연관표 분석 웹앱

한국은행 「2023년 산업연관표(연장표)」의 **기본부문(380)·소분류(165)·중분류(83)·대분류(33)** 투입산출표를 불러와 산업구조, 수요충격 파급효과, 전후방 연관효과, 최종수요 유발구조, 비용 상승의 가격 파급효과를 분석하는 웹앱입니다. 별도 서버 없이 GitHub Pages에 올린 정적 파일만으로 동작하며, 계산은 방문자의 브라우저에서 Python(Pyodide · numpy · openpyxl)으로 수행됩니다.

- 웹앱 주소: `https://USERNAME.github.io/Korea_IO_2023/` ← 본인 사용자명·저장소명으로 바꿔 적기
- 기준: 2023년, 생산자가격, 당해년 가격 (2020년 실측표 기준 연장표)

## 2. 자료 출처·단위·공개 권한

- **출처**: 한국은행 경제통계시스템(ECOS, https://ecos.bok.or.kr) 「2023년 산업연관표(연장표)」 투입산출표(생산자가격), 「2020 기준년 상품분류(투입산출표)」. 한국은행 보도자료 「2023년 산업연관표(연장표)」(2025.9.24)의 공표치를 검증 기준으로 사용.
- **공개 권한**: 한국은행이 일반에 무료로 공개하는 국가 공식 통계이며 출처를 밝혀 사용합니다. 산업 단위 집계 자료로 **개인정보·비밀번호·API 키는 포함되어 있지 않습니다.**
- **소분류·중분류 파일**: ECOS의 소분류·중분류 표 대신, 한국은행 부문분류표(기본→소→중→대 대응)에 따라 기본부문 거래표를 합산해 같은 12개 시트 형식으로 만들었습니다(`tools/build_level_workbooks.py`). 거래표는 행·열을 그대로 더하고, 계수·유발계수·유발액은 합산된 거래표로 다시 계산합니다. **같은 방법으로 만든 대분류가 한국은행 공식 대분류 파일과 총산출·생산유발계수 모두 오차 0으로 일치**하므로, 소·중분류도 한은 방식과 같은 결과입니다. 한은 공식 소·중분류 파일로 바꾸려면 같은 이름으로 `data/`에 덮어쓰면 됩니다.
- **금액 단위**: 백만원(당해년 가격, 생산자가격). 1,000백만원 = 10억원, 1,000,000백만원 = 1조원. 화면의 '조원' 표기는 백만원 ÷ 1,000,000.
- **계수 단위**: 투입계수·유발계수는 무차원(원/원) — 산출 또는 최종수요 1원당 금액. 영향력·감응도계수는 전산업 평균을 1로 한 지수. 비율·구성비·의존도는 %, 가격 파급 결과는 %(기여도는 %p).

## 3. 사용법

1. 웹앱 주소에 접속하면 Python 실행 환경(Pyodide)이 자동으로 준비됩니다(첫 접속 약 5~20초).
2. **① 자료 불러오기**에서 `4개 분류 모두 불러오기`(또는 분류별 버튼)를 누릅니다. 각 카드에 부문 수, 시트 수, `✓ 검증 통과` 여부가 표시되고, `검증 상세`에서 재계산 오차를 볼 수 있습니다. 13부문·7부문·1부문은 대분류를 합산해 자동으로 만들어집니다.
3. 화면 위쪽 **분석 기준 분류**에서 기본부문~1부문 중 하나를 고르면 ③~⑦ 분석이 그 분류로 다시 계산됩니다.
4. 각 탭의 기능:

| 탭 | 하는 일 |
|---|---|
| ② 원자료 탐색 | (1) 모든 분류에서 산업명·코드 통합 검색 + 상위 분류 경로 표시, (2) 대분류→중분류→소분류→기본부문 순으로 분류 체계 따라가기, (3) 분류·시트·행을 골라 원표 값을 그대로 확인(행·열 검색, 셀별 단위 표시) |

### 분석 예시

- **반도체 수출 10% 감소** (④, 기본부문, `예시` 버튼): 집적회로 수출(국산) 97.2조원의 10%인 9.72조원이 줄면 전 산업 생산이 14.66조원(생산유발 1.508배), 부가가치가 5.55조원, 수입이 4.17조원 감소합니다. 생산 감소의 70%가 대분류 '컴퓨터, 전자 및 광학기기'에, 나머지는 제조임가공·화력발전·도소매 등에 나타납니다.
- **전력·가스·증기 가격 10% 인상** (⑦, 대분류): 소비자물가(민간소비 가중) +0.45%, 국내 생산자가격(산출 가중) +0.59%. 1차 금속(+0.95%)·비금속광물(+0.78%)처럼 에너지를 많이 쓰는 산업의 가격 상승이 큽니다.
- **집계 편의** (⑧, 대분류 C09 → 기본부문): 같은 1조원이라도 대분류 하나로 계산하면 생산유발 1.718조원이지만, 기본부문별로는 1.214조원(기타 무선통신장비)~2.643조원으로 크게 다릅니다.

## 4. 분석 방법

표기: n개 부문, 국산거래 Z<sub>d</sub>, 수입거래 Z<sub>m</sub>, 총산출 x, 국산 최종수요 F<sub>d</sub>(n×7: 민간소비·정부소비·민간투자·정부투자·재고증감·귀중품·수출), 수입 최종수요 F<sub>m</sub>, 부가가치 VA.

| 개념 | 계산 |
|---|---|
| 국산·수입 투입계수 | A<sub>d</sub> = Z<sub>d</sub> diag(x)<sup>−1</sup>, A<sub>m</sub> = Z<sub>m</sub> diag(x)<sup>−1</sup> (총산출 0인 부문은 0) |
| 생산유발계수(레온티에프 역행렬) | L = (I − A<sub>d</sub>)<sup>−1</sup> |
| 수입·부가가치유발계수 | M = A<sub>m</sub> L, V = diag(v) L, v = VA / x |
| 부문별 유발계수 | L·M·V의 열합. 국산품 1원의 수요는 부가가치와 수입으로 모두 나뉘므로 V열합 + M열합 = 1 |
| 수요충격 | Δx = L Δf, Δ부가가치 = v ⊙ Δx, Δ수입 = A<sub>m</sub> Δx, 직접효과 = Δf, 간접효과 = Δx − Δf |
| 영향력계수(후방) | L 열합 ÷ 전체 열합 평균 |
| 감응도계수(전방) | L 행합 ÷ 전체 행합 평균 |
| 최종수요 항목별 유발 | 생산 L F<sub>d</sub>, 부가가치 V F<sub>d</sub>, 수입 M F<sub>d</sub> + F<sub>m</sub>. 생산·부가가치 유발계수는 ÷ 국산 최종수요, 수입유발계수는 ÷ (국산+수입) 최종수요 |
| 유발의존도 | 산업 i 총산출 중 소비·투자·수출이 각각 유발한 비중 = (L F<sub>d</sub>)<sub>i,항목</sub> / x<sub>i</sub> |
| 가격 파급(비용 전가) | p′ = p′A<sub>d</sub> + p<sub>m</sub>′A<sub>m</sub> + v′ ⇒ Δp′ = (Δp<sub>m</sub>′A<sub>m</sub> + Δv′) L. 특정 부문 E를 외생 인상할 때 나머지 N: Δp<sub>N</sub>′ = Δp<sub>E</sub>′ A<sub>d,EN</sub> (I − A<sub>d,NN</sub>)<sup>−1</sup>. 임금 r% 상승: Δv = r × (피용자보수/산출) |
| 물가지수 영향 | 소비자물가 = Σ(국산 민간소비·Δp + 수입 민간소비·Δp<sub>m</sub>) / 민간소비 합. 생산자가격 = 산출 가중, 수출가격 = 국산 수출 가중, 투자재 = 고정자본형성 가중 |
| 분류 합산 | 0/1 대응행렬 S로 Z′ = S Z Sᵀ, x′ = S x, F′ = S F, VA′ = VA Sᵀ 후 위 계산을 다시 수행 |
| 13·7부문 | 한은 보도자료의 부문 구성(농림수산품, 광산품, 소비재·기초소재·조립가공 제품, 제조임가공·수리, 전력·가스·수도 및 폐기물, 건설, 도소매 및 운송, 생산자·사회·소비자 서비스, 기타)을 대분류 기준으로 재구성 |

## 5. 검증 결과

엑셀을 불러올 때마다 다음을 자동으로 검사합니다(①의 `검증 상세`, ⑨ 탭).

1. **원표 재현**: 거래표로 다시 계산한 A<sub>d</sub>, A<sub>m</sub>, L, M, V와 최종수요 항목별 유발액이 원표 시트와 일치하는지 — 4개 파일 모두 최대 오차 10<sup>−15</sup> 수준.
2. **회계 항등식**: 총거래 = 국산 + 수입, 부가가치계 = 항목 합, 총산출 = L × 국산 최종수요.
3. **파일 간 일관성**: 기본부문을 합산한 결과 vs 소·중·대분류 파일 — 총산출·생산유발계수 차이 0.

## 6. 모형의 한계

- 투입계수 고정(규모의 경제·가격에 따른 투입 대체 없음), 공급능력 제약 없음, 수입 비율 고정 → 충격이 클수록 효과를 과대평가할 수 있습니다.
- 가격모형은 비용 상승분 100% 전가, 임금-물가 연쇄와 수요 감소 반영 없음 → 상한(최대 파급) 추정치입니다.
- 연장표는 2020년 실측표를 바탕으로 간접 추계한 표이므로, 세부 부문일수록 추계 오차가 있을 수 있습니다.
- 고용표(취업·고용유발계수)는 포함하지 않았습니다.
